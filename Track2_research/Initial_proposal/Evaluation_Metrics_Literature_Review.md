# Track 2 — Evaluation metrics literature review

Jingfen supplied the Grep Search Literature PDF for Track 1, the method and harness direction. The review below builds Track 2 from evaluation studies, benchmarks and metric papers found through independent searches for search trajectory diagnosis, session retrieval, reformulation and annotated support. The team’s selection criteria are whether a measure isolates a meaningful stage, supports a fair comparison and can be validated with RISE records. The meeting reconstruction suggests evaluating query formulation, workspace construction and utilization, but the metric choices are our proposal.

## Independent evaluation research

| Primary work | Actual method and evaluation | Application, data and limits |
|---|---|---|
| [Liu et al., Diagnosing Search Behavior and Failure Modes](https://arxiv.org/html/2608.01913) | Compares six agents under fixed retrieval and harness on BrowseComp-Plus, with an open-web follow-up. On incorrect trajectories a retrieval gap means the cumulative retrieved set misses all gold documents; a utilization gap means it contains at least one. It examines per-step recall and the arrival of evidence as well as effort. | Reproduce the document-level split as the baseline, then test how many utilization-gap cases instead stop at staged but unseen, partial evidence or unresolved logging. Needs qrels, inventories and verdicts for the baseline, plus span coverage for the refinement. Some gold does not imply enough evidence. |
| [Ning et al., Agentic Search in the Wild](https://arxiv.org/html/2601.17617) | Labels reformulations and proposes Context-driven Term Adoption Rate (CTAR). For a query transition let N be unique lowercased non-stopword terms newly present relative to the previous query, C the terms in last-step or accumulated returned text. CTAR = size of N intersect C / size of N, zero if either is empty. | Optional exploratory adaptation uses only observed body and previews before the next model decision. Keep same-batch calls unordered and missing text unresolved. Lexical overlap can arise by chance and misses paraphrases. It measures neither quality nor causal evidence use. |
| [TREC CAsT 2020](https://trec.nist.gov/pubs/trec29/papers/OVERVIEW.C.pdf) and [ECAsT](https://pmc.ncbi.nlm.nih.gov/articles/PMC10280565/) | CAsT evaluates contextual retrieval with human rewrites and automatic runs using ranked passage metrics. ECAsT tests robustness across manual and raw paraphrases through fixed pipeline stages. | Re-rank full question, first agent query and recorded reformulations against the same index. Compare paired changes in labeled gain. CAsT utterances share a user-provided conversation, whereas RISE policies create their own histories. Treat manual rewrites as references if later available, and avoid string similarity as the main quality measure. |
| [Järvelin and Kekäläinen, Cumulated gain](https://doi.org/10.1145/582415.582418) | Introduces cumulated gain measures and comparison to ideal gain using graded judgments. A common modern variant uses DCG = sum over ranks r ≤ K of (2^grade − 1)/log2(r+1), with nDCG = DCG/ideal DCG. | Apply to ranked query results only. Sparse binary gold qrels and deep staging ranks limit interpretation. A workspace is a set and some retrieved items are never shown. |
| [Clarke et al., Novelty and diversity](https://doi.org/10.1145/1390334.1390446) | Rewards coverage of information nuggets and downweights repeated coverage. In alpha-DCG, each nugget hit at rank r is weighted by (1−alpha) to the power of the number of earlier hits, then discounted by log2(r+1). | Inspires clue novelty, but needs reliable passage-to-clue judgments and a defined order. Prefer a raw clue coverage curve because RISE tool budgets and batch ordering differ from ranked examination. |
| [Mind2Web 2](https://proceedings.neurips.cc/paper_files/paper/2025/hash/fdcec9f5b99aa4fc8f4fb8487802d737-Abstract-Datasets_and_Benchmarks_Track.html) | Evaluates answer correctness and attribution on long-horizon web tasks with task-specific tree rubrics and judges. | Borrow requirement-by-requirement rubrics and evidence provenance. A proposed RISE rubric records each required clue, evidence anchors and whether one valid route is complete. Existing concise answers usually cannot support citation scoring. |
| [InfoDeepSeek](https://arxiv.org/abs/2505.15872) | Benchmarks open-web agentic information seeking and motivates going beyond fixed document gold sets in dynamic environments. | Supports accepting alternate evidence during annotation. Do not transfer assumptions about a changing web to the pinned RISE corpus or import a benchmark score wholesale. |
| [TREC Session Track](https://trec.nist.gov/pubs/trec19/papers/SESSION.OVERVIEW.2010.pdf) and [Dynamic Domain](https://trec.nist.gov/pubs/trec26/papers/Overview-DD.pdf) | Session DCG discounts across rank and queries. Dynamic Domain uses subtopic judgments and gain sensitive to novelty and cost. | Qrels and archived rankings permit rank and marginal coverage analyses. Use plain gain curves as primary. A human examination discount does not encode RISE's top-10 preview plus grep interface. Subtopic coverage needs claim labels. |
| [How AI agents search](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0360157) | Controlled search logs support analysis of repeated queries, reformulation transitions, decomposition and search effectiveness. | Exact normalized repeats and query transitions can be measured. Label semantic changes or clue incorporation on a sample. Repetition can be legitimate when state or retrieval scope changes. |
| [HotpotQA](https://arxiv.org/abs/1809.09600) | Sentence-level supporting facts and joint QA/support evaluation on multi-hop questions. | Borrow span annotation granularity and explicit joint success. BrowseComp-Plus qrels cannot substitute for supporting facts, and a single reference span can omit valid alternatives. |
| [RAGChecker](https://arxiv.org/abs/2408.08067) | Claim-level entailment diagnostics include retriever claim recall and generator-side context utilization and hallucination measures. | Adapt claim coverage on observed evidence with human review. Needs defensible claim decomposition and entailment. Flattening the entire workspace into context would falsely credit unseen evidence. |
| [ALCE](https://aclanthology.org/2023.emnlp-main.398/) | Answer correctness and citation quality, including entailment-based citation recall and precision. | Useful if a future harness emits span attributions. Short uncited answers permit manual answer support, with citation precision undefined and causal use unobserved. |
| [Cross-Lingual BrowseComp-Plus](https://arxiv.org/abs/2606.15345) | Answer accuracy, evidence recall, search behavior, citation fidelity and oracle retrieval under changed evidence language. | Illustrates usefulness of evidence-supplied comparisons even when retrieval is strong. Requires new continuations and does not isolate the BM25/SPLADE mechanism. |
| [BrowseComp-Plus](https://aclanthology.org/2026.acl-long.1023/) | Fixed corpus, benchmark answer judging, gold and evidence retrieval, comparison across retrievers and agents. | Gold/evidence qrels join to inventories and rankings. They label documents. | Labeled evidence is incomplete and need not exhaust alternate routes or identify the sufficient span. |

## Selective Track 1 cross-references

Each entry separates the paper’s own evaluation from the proposed IR2 use. These are cross-references to methods and diagnostic examples. Independent evaluation sources above determine the Track 2 baselines and validation protocol.

| Primary work | Actual evaluation or demonstrated methodology | Why it is relevant to Track 2 and what we would adapt | Limit |
|---|---|---|---|
| [RISE](https://arxiv.org/abs/2606.06880) and [official implementation](https://github.com/texttron/RISE) | Answer accuracy, cost and runtime across workspace and baseline variants, plus retrieval depth and corpus scaling. Top-K per query builds an explorable union while previews expose a smaller set. | Existing final verdicts, qrels and inventories reproduce end points. Plotting a passage-level trajectory is our adaptation. | A final inventory has no per-document arrival times. RISE interfaces bundle workspace, preview and navigation differences. |
| [AtlasNav: Evidence Blindness](https://arxiv.org/abs/2608.24764) | Stage-wise realization from evidence surfacing through opening and fragment localization, budgeted realization, and same-model evidence-supplied reference. | Closest precedent for our stage and budget curves. Local adaptation needs attributable text and criteria for a complete evidence set. | Its navigation policy and observation schema differ. Treat evidence-supplied performance as an empirical reference under a changed information condition. |
| [SearchAtlas](https://arxiv.org/abs/2609.10901) | Builds evidential query graphs linking earlier observations, queries, question constraints and answers. Checks extracted edges against human labels and reports mean edge F1 of 86%. | Adapt a small subset of edge types with paired human review. Full graph reconstruction is risky with prefix-only records. | An inferred provenance edge is observational. Reliable labels for query dependence are expensive. |
| [Bridge Evidence](https://arxiv.org/abs/2607.15253) | Intervenes on previously observed evidence and measures changes to subsequent queries, answers and search cost. Separates static relevance from counterfactual usefulness. | Use its intervention design for a future continuation pilot. Current logs can label a proposed bridge and record later reuse. | Removing text can change coherence, budget and subsequent state. Saved observational traces alone cannot reproduce its causal estimand. |
| [Is Grep All You Need?](https://arxiv.org/abs/2605.15184) | Compares grep and vector tools across harnesses and studies inline versus file-based delivery with answer performance and efficiency. | Borrow factorial controls and track observation budget. Saved RISE traces permit descriptive comparisons only. | Its task, tools and harnesses differ. Tool effects can depend on the delivery interface. |
| [Filesystem-Based Memory](https://arxiv.org/abs/2607.26637) | Varies memory organization, tool interfaces and scale, tracking answer quality, cost and store health. | Reuse the quality–cost reporting principle. Filesystem evolution and maintenance are outside the saved RISE runs. | A continually updated memory store is a different setting from a fixed corpus and a transient question workspace. |
| [GrepSeek](https://arxiv.org/abs/2605.29307), [Dr-DCI](https://arxiv.org/abs/2606.14885), [RARG](https://arxiv.org/abs/2607.24223), [IndexAct](https://arxiv.org/abs/2610.07960) | These systems vary shell training and efficient execution, dynamic pulling, relevance-ordered scanning, or persistent index-state operations respectively. Jingfen's map helps specify their differing observation boundaries. | Use them to motivate two controls: change search execution holding its output fixed, or change exposure holding the candidate set fixed. Per-tool counts across these systems are incomparable without a common model-decision or token axis. Their logs are outside the paired audit. |

## Comparison protocol and proposed contribution

Use the Liu et al. document-level diagnosis as a concrete benchmark for added explanatory value. Compare its paired error classification with a three-way span-aware classification: verified sufficient evidence, verified incomplete exposure on adequately observed trajectories, and unresolved observability. Break verified incomplete cases down by opportunity, visibility and body access. Some stages are nonnested across sources. Report linked, same-source transitions separately from any-source sufficiency. Use target sets defined before reading the outcomes and use all question pairs in primary budget curves. For agents without workspaces, opportunity is defined by the accessible corpus under that protocol and should be reported separately. Exposure and answer endpoints can still use common support definitions and a common decision or token budget.

The proposed contribution is estimating how often a document-level label conceals a more specific, verifiable failure, and checking whether independent reviewers agree about that diagnosis. It is an empirical test and annotation contribution. Neither stage-wise evaluation nor attribution analysis is new. The metric catalog specifies definitions, requirements, feasibility and caveats. The feasibility audit identifies the actual project records.
